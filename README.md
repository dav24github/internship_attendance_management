# Intern Attendance Management System

University internship project (2020) at my program's lab, Universidad San Francisco Xavier (Sucre, Bolivia). A web system to manage the attendance of the lab's interns.

## Features
- Intern management with history
- Schedules with per-day details
- Clock-in point that records attendance against each intern's schedule
- Absences, leave requests and inactivity periods
- Lateness and worked-days calculation
- PDF reports per intern (attendance, absences, leave, lateness)
- Token-based login

## Stack
Laravel (PHP) REST API · MySQL · Vue 2 + Vue Router · Bootstrap 4

## My role
Built most of the system, backend API and Vue frontend, with one teammate.

This was my first attendance system. Two years later I joined Tekov, where I spent 4 years building the frontend of an HR, attendance and payroll SaaS used in 4 countries.
